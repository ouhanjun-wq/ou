# 舵机接线与标定

这一页把 [新手计划](beginner-plan.md) 第 4–6 步讲得更细：舵机回中、找插口、量腿长、调方向、调中位。所有命令都在 Arduino IDE 的**串口监视器**里输入：115200 baud，换行（Newline）。

## 0. 编号约定

![腿和舵机编号](img/fig3-servo-numbers.svg)

- **腿号**：0 左前 LF，1 左中 LM，2 左后 LR，3 右前 RF，4 右中 RM，5 右后 RR。
- **关节号**：0 基节 coxa（左右摆），1 大腿 femur（上下抬），2 小腿 tibia（膝盖）。
- **舵机号**：

  $$n = 3 \times \text{腿号} + \text{关节号}, \qquad n = 0, 1, \dots, 17$$

  例如右前腿大腿：$n = 3 \times 3 + 1 = 10$。

- **关节角**：装配姿态时 3 个关节都是 $0^\circ$。正方向规定如下：
  - 基节：俯视逆时针为 +。
  - 大腿：抬起为 +。
  - 小腿：膝盖张开、脚尖往外为 +。

## 1. 舵机回中

舵机的“中间”是 1500 µs 的脉冲，这时舵机轴在它可转范围的正中间。装舵机臂之前先回中，保证装好后每个关节往两边都能转。

```text
centerall
```

- `centerall` 往**所有可能的插口**发 1500 µs，不需要先配好插口表：
  - 找到 PCA9685 芯片时，发给它的全部通道。
  - 否则发给 ESP32 上所有能安全输出的引脚。
- 保持通电，装舵机臂，让腿摆成装配姿态：基节垂直机身、大腿水平、小腿竖直向下。
- 装完输入 `off`，舵机放松。

> MG90S 的舵机臂有 20–25 个齿，一个齿大约 15°。对不准时选最近的齿，剩下的误差用第 5 节的 trim 补。

## 2. 找插口

固件要知道“$n$ 号舵机插在哪个插口”。插口有两种写法：

| 扩展板类型 | 怎么判断 | 插口写法 |
|---|---|---|
| PCA9685 型 | `i2c` 显示 `0x40`（可能还有 `0x41`） | 芯片地址 + 通道号，例如 `pca 0x40 3` |
| GPIO 直连型 | `i2c` 什么都没有 | ESP32 引脚号，例如 `gpio 13` |

第一次开机时，固件会按板子类型猜一张表：
- PCA9685 型：左边 3 条腿 → `0x40` 通道 0–8，右边 → `0x41` 通道 0–8。
- GPIO 型：见 `servo_out.h` 里的 `defaultGpio`。

猜对了最好，猜错了用下面的方法改。

### 方法：让插口轮流摆动，看哪个关节动

1. 架空机器人，打开电池，确认舵机是 OFF 状态（刚开机就是；否则输入 `off`）。
2. 输入 `findall`。每个插口会摆动 3 秒，串口显示当前插口：

   ```text
   wiggling PCA9685 0x40 channel 0 ... which servo moves?
   wiggling PCA9685 0x40 channel 1 ... which servo moves?
   ```

3. 对照上面的编号图，记下每个插口对应的舵机号。中途想停，输入 `stop`。只想单独试一个插口：
   - `findpca 0x40 5`：只摆 PCA9685 `0x40` 的 5 号通道。
   - `find 13`：只摆 GPIO 13。
4. 用 `map` 写进去：

   ```text
   map 0 pca 0x40 0
   map 1 pca 0x40 1
   map 10 gpio 13
   map 17 none
   ```

   `none` 表示这个舵机暂时不接。
5. `maps` 显示整张表，检查 18 行没有重复。
6. `save` 保存到主板 flash，断电不丢。

### 例子：记录表

| 看到在摆的 | 是哪个关节 | 舵机号 | 命令 |
|---|---|---|---|
| 0x40 ch 0 | 左前 基节 | 0 | `map 0 pca 0x40 0` |
| 0x40 ch 1 | 左前 大腿 | 1 | `map 1 pca 0x40 1` |
| … | … | … | … |
| 0x41 ch 8 | 右后 小腿 | 17 | `map 17 pca 0x41 8` |

## 3. 量腿长

![量腿长](img/fig4-leg-measure.svg)

量**转轴中心到转轴中心**的距离，单位毫米：

| 参数 | 从 | 到 | 默认值 |
|---|---|---|---|
| `coxa` | 基节舵机的转轴（竖直） | 大腿舵机的转轴 | 28 |
| `femur` | 大腿舵机的转轴 | 小腿舵机的转轴（膝） | 50 |
| `tibia` | 膝 | 脚尖 | 75 |

```text
set coxa 30
set femur 52
set tibia 78
```

腿在机身上的安装位置也可以改，平时不用动：
- `front_x`、`front_y`：前腿转轴的坐标。
- `mid_y`：中腿转轴到中线的距离。
- `rear_x`、`rear_y`：后腿转轴的坐标。
- `front_angle`、`rear_angle`：前腿、后腿指向的角度。

完整参数表见 [固件与命令](firmware.md#参数表)。

## 4. 调方向（dir）

同一型号的舵机，装在左边和右边时方向是镜像的。所以每个舵机都要确认一次方向：

```text
joint 1 20
```

`joint 1 20` 让 1 号舵机（左前大腿）转到 $+20^\circ$。它应该**抬起**；如果是往下压，就输入：

```text
dir 1 -1
```

18 个舵机都这样检查一遍：

| 关节 | `joint n 20` 时正确的动作 |
|---|---|
| 基节（n = 0, 3, 6, 9, 12, 15） | 俯视看，腿**逆时针**摆 |
| 大腿（n = 1, 4, 7, 10, 13, 16） | 大腿**抬起** |
| 小腿（n = 2, 5, 8, 11, 14, 17） | 膝盖**张开**，脚尖往外 |

## 5. 调中位（trim）

```text
center
```

`center` 让所有关节回到 $0^\circ$，也就是装配姿态。哪个关节没对准，就给它加一点偏移：

```text
trim 7 -30
```

- 单位是 µs。MG90S 转 180° 对应 2000 µs，所以 $1^\circ \approx 11.1\ \mu\text{s}$。
- 一次改 10–20，改完会马上动到新位置，看着调。
- 超过 $\pm 150\ \mu\text{s}$（约 $13^\circ$）说明舵机臂装偏了一个齿以上，回第 1 节重新装。

全部调好后：

```text
save
```

## 6. 检查清单

- [ ] `maps`：18 个舵机都有插口，没有重复
- [ ] `joint n 20`：18 个舵机方向都对
- [ ] `center`：6 条腿对称，大腿水平、小腿竖直
- [ ] 腿长已经 `set`，并且 `save` 过
- [ ] `stand` 能站稳，`status` 里没有 `out of reach` 警告
