# 体感手套控制的六足机器人（Gesture Glove Hexapod）

> 这个文件夹是六足机器人项目（仓库根目录是 6 自由度机械臂，[`butterfly/`](../butterfly/README.md) 是仿生蝴蝶）。

**六足机器人套件**（ESP32 + 舵机扩展板 + 18 × MG90S + 双 18650）加一只自己做的**体感手套**（XIAO ESP32S3 + MPU6050 + 5 根弯曲传感器）：

- ✋ 张开手：手掌前倾 = 前进，左右翻 = 转弯
- ☝️ 伸食指：横移（螃蟹步）
- ✌️ 剪刀手：机身跟着手掌倾斜
- ✊ 握拳：立刻停
- 👍 竖拇指 1 秒：起立 / 趴下
- 🤘 摇滚手势：换步态（三角 / 涟漪 / 波浪）

手套和机器人之间用 **ESP-NOW** 直连（不需要路由器），手套断电后机器人 1 秒内自动停稳；电量低手套振动，过低机器人自己趴下。

## 硬件一览

| 部分 | 型号 | 来源 |
|---|---|---|
| 机器人主控 | ESP32 DevKit + 舵机扩展板（PCA9685 型或直连 GPIO 型都支持） | 套件 |
| 舵机 | 18 × MG90S | 套件 |
| 机器人电源 | 2 × 18650（7.4 V）+ 电压检测模块（低电量保护） | 套件 + 学习套件 |
| 手套主控 | Seeed XIAO ESP32S3（自带锂电池充电） | 要买 |
| 手套传感器 | MPU6050（GY-521）+ 5 × 2.2 寸弯曲传感器 | 要买 |
| 手套其他 | 迷你面包板、按键、振动马达模块、3.7 V 500 mAh 锂电池 | 要买 / 元件包 |
| 可选 | HC-SR04 超声波避障 | 学习套件 |

手套部分约 **150–280 元**，机器人不用再买什么（最多一个 6 V 降压模块）。
