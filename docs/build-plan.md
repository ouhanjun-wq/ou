## 最终目标（验收标准）

1. **手柄操控**：用盖世小鸡 G7 Pro，在 **XYZ 模式**下让夹爪前后、左右、上下走直线，并能调整俯仰和旋转。
2. **抓取搬运**：30 秒内把一个约 50 g 的小方块，从 A 点搬到 200 mm 外的 B 点，放稳。
3. **示教回放**：示教一段“抓起 → 搬运 → 放下 → 回原位”的动作（6 个以上路点），**循环回放 10 次全部成功**。
4. **安全**：急停测试、过载测试、夹爪自适应测试都通过（阶段 7）。
5. **扩展接口**：手机网页能看状态、发指令；电脑脚本能发 `MOVE` / `GRIP` 指令（阶段 9 可选：语音）。

## 手柄怎么操控

![图 5 G7 Pro 按键功能](img/fig5-gamepad.svg)

| 按键 | 关节模式 | XYZ 模式 |
|---|---|---|
| 左摇杆 左 / 右 | J1 底座左转 / 右转 | 夹爪左移 / 右移 |
| 左摇杆 上 / 下 | J2 大臂抬起 / 放下 | 夹爪前进 / 后退 |
| 右摇杆 上 / 下 | J3 小臂抬起 / 放下 | 夹爪上升 / 下降 |
| 右摇杆 左 / 右 | J4 手腕抬头 / 低头 | 夹爪抬头 / 低头（俯仰） |
| 十字键 ← / → | J5 手腕旋转 | J5 手腕旋转 |
| RT / LT | 夹爪闭合 / 张开（按得越深越快，夹到东西自动停） | 同左 |
| **Menu（≡）** | 给舵机上电；再按一次：回停放姿态后断电 | 同左 |
| **View（⧉）** | 切换 关节 / XYZ 模式 | 同左 |
| Y | 回原位（HOME） | 同左 |
| B | 停止；过载后按 B 恢复 | 同左 |
| A | 记录路点；**长按 2 秒**清空全部 | 同左 |
| X | 播放一次；**长按 1 秒**循环播放 | 同左 |
| LB / RB | 速度 慢 ↔ 中 ↔ 快 | 同左 |
| 十字键 ↓ / ↑ | 删除最后一个路点 / **长按 1 秒**保存路点到 flash | 同左 |

**“自主调节保持稳定”在机械臂上是这样实现的**（原理见 [运动控制原理](motion-control.md)）：

- 松开摇杆，关节就停在当前角度。舵机自带位置闭环，受到外力也会顶回原位。
- 所有动作都经过速度和加速度限制，起步和停下都很柔和，不会甩。
- XYZ 模式下由逆运动学自动协调 J1–J4：夹爪走直线，俯仰角保持不变。
- 碰到限位、桌面、自身时自动停下并沿边界滑动；撞到障碍物或堵转时自动冻结，然后断电保护。

## 2. 分阶段步骤

每个阶段都有**出口条件**。达不到就先别往下做，按第 3 节排查。

### 阶段 0：准备（半天）

- [ ] 按 BOM 下单。支架套件到货后，先对照清单点一遍零件。
- [ ] 电脑装好 **Arduino IDE 2.x**，按 [firmware/README.md](../firmware/README.md) 添加 **Bluepad32 开发板包**，开发板选 **“ESP32 Dev Module”**（esp32_bluepad32 分类下）。
- [ ] 手机装一个“水平仪”App。

**出口**：Arduino IDE 能编译 `firmware/arm_controller`（编译通过即可，这一步还不用接硬件）。

### 阶段 1：主控 + 手柄（半天）

- [ ] 只接 USB 线，给 ESP32 上传 `arm_controller`。
- [ ] 打开串口监视器（115200），看到 `ready`。这时还没接 PCA9685，会提示 `PCA9685 NOT FOUND`，属于正常。
- [ ] G7 Pro：背面开关拨到**蓝牙**，按 Xbox 键开机，**长按配对键**。串口出现 `gamepad connected`，手柄震一下。
- [ ] 手机连 Wi-Fi **RobotArm**（密码 `robotarm123`），浏览器打开 `192.168.4.1`，能看到状态页，“手柄”显示“已连接”。

**出口**：手柄能连上，手机网页能打开。

### 阶段 2：电源（1 天）

按[组装指南第 1 步](assembly-guide.md#第-1-步电源)操作。

- [ ] **不接任何负载**，把大降压模块调到 **6.0 V**，MP1584 调到 **5.0 V**，用万用表确认。
- [ ] 按图 1 接好：DC 母座 → 保险丝 → 开关 → 两个降压模块；6 V 支路：急停 → 继电器 → INA226 → 舵机母线（+ 2 × 2200 µF 电容）。
- [ ] 通电前量一遍：12 V、6 V、5 V 对 GND 都**不短路**。
- [ ] 通电：5 V 输出正常。继电器还没吸合，舵机母线应该是 0 V。

**出口**：三路电压正确，急停按下 / 松开都不影响 5 V。

### 阶段 3：驱动板和传感器（半天）

- [ ] PCA9685 板上的 **A0 焊盘用锡短接**，地址变成 0x41。
- [ ] 按图 2 接 I²C、继电器、蜂鸣器。ESP32 的 5 V 改从 MP1584（经 SS14）供电。
- [ ] 串口输入 `I2C`，应该看到 `0x40 0x41`（还可能看到 `0x70`，这是 PCA9685 的广播地址，正常）。
- [ ] 按 Menu（或输入 `ON`）：继电器“咔哒”一声，蜂鸣器响一声，网页显示舵机电压约 6.0 V。再按 Menu：继电器断开。
- [ ] 按下急停：网页显示电压约 0 V，状态变成 **E-STOP**，继电器也断开。

**出口**：I²C 两个地址都在，继电器受控，急停能被识别。

### 阶段 4：舵机回中（半天）

按[组装指南第 3 步](assembly-guide.md#第-3-步舵机测试和回中装支架之前必须做)操作。

- [ ] 6 个舵机插到 PCA9685 通道 0–5（图 3），**先不装到支架上**。
- [ ] `ON` 之后，依次输入 `PULSE 1 1500` … `PULSE 6 1500`，所有舵机转到中位。
- [ ] 每个舵机都用 `PULSE j 1000`、`PULSE j 2000` 试一下，能左右转动，没有异响。
- [ ] 直接输入 `OFF`（不要先 `PULSE OFF`）。**这时舵机都停在中位，保持别动**，下一步装支架。

**出口**：6 个舵机都能转，都停在中位。

### 阶段 5：机械装配（1–2 天）

按[组装指南第 4 步](assembly-guide.md#第-4-步机械装配)和图 8 操作。

- [ ] 底座 → J1 → J2 肩部支架 → 大臂 → J3 → 小臂 → J4 / J5 手腕 → J6 夹爪。
- [ ] 每装一个舵盘，都对准“中位姿态”：J2 中位时大臂竖直，J3 中位时小臂水平，J4 中位时手腕伸直，J5 中位时夹爪两指左右张开，J6 中位时夹爪半开。
- [ ] 舵盘螺丝点螺丝胶；有轴承的那一侧不要漏装。
- [ ] 底座用 4 颗 M4 螺丝固定在底板上，底板用 F 型夹夹在桌边（图 6）。

**出口**：断电时，每个关节只能在转动方向上动，其他方向不晃。

### 阶段 6：标定（半天）

按[组装指南第 6 步](assembly-guide.md#第-6-步标定每个关节都要做)和图 7 操作。

- [ ] 用游标卡尺量 $d_1, L_2, L_3, L_4$（图 4），`SET d1 …`、`SET l2 …`、`SET l3 …`、`SET l4 …`。
- [ ] 先把上电姿态临时改成中位姿态（`SET j2_park 90` 等，见组装指南 6.2），再给每个关节做两点标定（`PULSE` 调姿态 → `MARK`），最后把停放姿态改回来。
- [ ] 夹爪：全开 `MARK 6 0`，刚好合拢 `MARK 6 100`。
- [ ] 检查限位：`J 2 20`、`J 2 160` 等，确认各关节在 `qmin` / `qmax` 附近不会碰到自己或底座。碰到就调小限位（`SET j2_qmin …`）。
- [ ] `SAVE PARAMS`。
- [ ] 验证：`HOME` 以后，用尺子量工具点，离桌面应该 ≈ 网页显示的 Z（误差 ≤ 10 mm）。

**出口**：`MOVE 160 0 40 -90` 以后，夹爪竖直朝下，离桌面约 40 mm，正对前方 160 mm 处（误差 ≤ 10 mm）。

### 阶段 7：手柄操控和保护测试（1 天）

- [ ] 速度调到“慢”（LB），关节模式下逐个关节试一遍方向，应该和图 5 一致。
- [ ] View 切到 XYZ 模式：推左摇杆前进，夹爪应该**水平直线**前进，高度基本不变。
- [ ] 推到够不到的地方：夹爪停住，手柄短震，而且会沿边界滑动。
- [ ] **夹爪测试**：按住 RT 夹一个纸盒，夹住后应该自动停止（串口显示 `object gripped`），舵机不应该持续嗡嗡响。
- [ ] **过载测试**：慢速下让大臂轻轻压住一本软书，0.5 秒后应该进入 **OVERLOAD**（长震 + 3 声），按 B 恢复。
- [ ] **急停测试**：运动中拍下急停，手臂断电（会软下来，手不要放在下面），网页显示 **E-STOP**。松开急停，扶到停放姿态，按 Menu 恢复。
- [ ] 完成验收第 2 项：30 秒内搬运方块。

**出口**：以上全部通过。

## 3. 故障排查

| 现象 | 可能原因 | 解决 |
|---|---|---|
| 手柄连不上 | G7 Pro 在 2.4G / 有线模式；以前配对过别的设备；板子是 ESP32-S3 / C3 | 背面开关拨到蓝牙，长按配对键；串口输入 `PAIR`；换原版 ESP32 |
| `PCA9685 NOT FOUND` | A0 没短接；SDA / SCL 接反；VCC 没接 | 输入 `I2C` 看地址；检查图 2 接线 |
| `INA226 not found` | 模块地址被改过；SDA / SCL 接反 | `I2C` 应该看到 0x40 |
| 上电舵机乱抖 | 舵机电源电压跌落；地线太细或没共地 | 6 V 和 GND 用 18 AWG；所有 GND 汇到一点；加上 2200 µF 电容 |
| ESP32 在舵机动的时候重启 | ESP32 和舵机共用电源，被拉低了 | ESP32 必须单独由 MP1584 供 5 V（图 1） |
| 按 Menu 继电器不吸合 | 继电器跳线设成了“低电平触发”；3.3 V 驱动不了 | 跳线改到“高电平触发（H）”；换标注 3.3 V 可触发的模块 |
| 某个关节方向反了 | 标定时两个 MARK 的角度写反了 | 重新做这个关节的两点标定 |
| XYZ 模式走的不是直线 | 连杆长度没量准；标定误差大 | 重新量 $L_2, L_3, L_4$；重新标定（用水平仪） |
| 老是 OVERLOAD | `over_amps` 太小；某个关节卡住或装歪了 | 断电手动转一转找卡点；适当提高 `over_amps`（≤ 8） |
| 夹不住东西就停了 | `grip_amps` 太小 | `SET grip_amps 0.9` |
| 夹住后舵机一直嗡嗡响 | 没接 INA226，或 `grip_amps` 太大 | 接好 INA226；降低 `grip_amps` |
| 手臂下垂、抖动 | J2 扭矩不够；负载太重；`amax` 太大 | 负载 ≤ 100 g；降低 J2 的 `amax`；检查 J2 是不是 DS3225 |
| 回放位置有偏差 | 舵机本身有 1–2° 的死区；负载不同 | 属于舵机方案的正常误差（约 ±3 mm）；关键点可以多录一个路点 |

## 4. 安全规则

1. **每次上电前**，先把手臂摆到停放姿态附近（图 4 的折叠姿态）。舵机没有位置反馈，上电瞬间会全速转到停放姿态。
2. 第一次运行用**最低速度**（LB 按到“慢”）。手和脸不要进入工作半径（约 330 mm，见图 6）。
3. **急停开关**放在伸手就能拍到的地方。拍下后手臂会失去力量软下来，下方不要放易碎物品。
4. 断电用 **Menu（停放后断电）**，不要直接拔电源。
5. 大降压模块和舵机长时间工作会发热。连续运行 30 分钟以上要检查温度，烫手就停下来休息。
6. 12 V 电源用正规的带认证适配器。**不要**用拆机电源或裸露的开关电源板。
